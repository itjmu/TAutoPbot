# Управление пользователями

Открыть: Настройки → Админ-панель → Пользователи. Доступ определяется ADMIN_ID в конфигурации. Новые действия разрешены только в личном чате администратора.

- Список по 12 пользователей с переходами страниц; поиск по Telegram ID или сохранённому @username.
- В карточке: блокировка/разблокировка, индивидуальные лимиты каналов, источников, новых постов, обложек, скачиваний видео и цветов кнопок.
- 0 запрещает соответствующее действие; −1 снимает численный лимит, кроме цветов (0–3). «тариф» возвращает лимит текущего тарифа. Суточная статистика при смене лимита не обнуляется. Уменьшение лимита каналов/источников делает лишние объекты недоступными, но не удаляет их.
- Удаление профиля требует подтверждения в интерфейсе, блокирует пользователя, удаляет строку профиля, языковые настройки и личное FSM-состояние. Платёжная история, Premium, связанные публикации и идентификатор блокировки сохраняются. Это не полное уничтожение всех связанных данных. После разблокировки пользователь сможет снова зарегистрироваться через /start.
- Блокировка отменяет активную задачу загрузки и запрещает последующие обычные обращения; уже принятый Telegram запрос нельзя отозвать. Подтверждённые платежи обрабатываются даже после блокировки.

Админ-панель → Экспорт данных:

- CSV UTF-8 с BOM: все строки users, профиль, даты, Premium, язык/часовой пояс, блокировка, личные лимиты и количество каналов/постов. Начала ячеек, похожие на формулы электронных таблиц, экранируются.
- SQLite: полный согласованный снимок базы, включая платежи и публикации. Используется SQLite Backup API; WAL не теряется. Временный файл удаляется после отправки или ошибки.
- Отправка только на ADMIN_ID в личный чат. Файлы более 49 МБ не отправляются, интерфейс сообщает о необходимости экспорта на сервере.

CSV не является полным экспортом всех связанных таблиц: для этого используйте SQLite. Телефоны и иные данные, которые бот не собирает, в выгрузке отсутствуют. После скачивания копия файла остаётся у администратора в Telegram.
