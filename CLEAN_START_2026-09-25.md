# Чистый старт и кнопки

По явному подтверждению пользователя рабочая база полностью сброшена без новой резервной копии. Три старые копии из backups удалены, оставшаяся временная база живого теста удалена. Пользователи, Premium, платежи, каналы, публикации, конкурсы, FSM и очереди в SQLite пусты. Оставлены только семь стандартных настроек приложения. Целостность базы проверена.

Меню используют значки действий и максимум три кнопки в строке. Длинные подписи получают одну или две колонки, короткие списки действий группируются по две. Возврат остаётся отдельной строкой. Подписи пользовательских кнопок в публикациях не изменяются, но ширина их рядов также ограничена.

После отдельного явного подтверждения пользователя ожидающие события Telegram удалены. Telegram подтвердил 0 ожидающих событий. Polling не запускался; сообщения в каналах не удалялись.

Актуальные протоколы: clean_reset_results.json, button_tests.log. Старые отчёты аудита описывают состояние до сброса; перечисленные там резервные копии больше не существуют.
